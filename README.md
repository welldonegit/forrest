# FORREST Trinity Resort — landing + styleguide

Чистий HTML + CSS під збірку **Vite**, розділені розмітка і стилі, з токенізованою
системою розмірів. Розмітка навмисно «пласка» й семантична: сторінка імпортується у
Figma плагіном **html.to.design**, і дерево DOM напряму стає деревом шарів.

## Запуск

Потрібен Node 18+.

```bash
npm install      # встановити Vite
npm run dev      # дев-сервер (http://localhost:5173)
npm run build    # прод-збірка у dist/
npm run preview  # переглянути зібране
```

Дві точки входу (multi-page): `index.html` (лендинг) і `styleguide.html` (система).

## Структура

```
index.html            # лендинг: header · hero · stats · footer
styleguide.html       # уся система: палітра, типографіка, шкала, компоненти
styles/
  main.css            # entry — імпортує все нижче в порядку каскаду
  tokens.css          # усі дизайн-токени (єдине джерело значень)
  reset.css           # структурний reset
  typography.css      # @font-face + класи .type-* + посилання
  layout.css          # контейнер, секції, 12-колонкова сітка
  styleguide.css      # оформлення сторінки стайлгайду (класи .sg-*)
  components/          # один компонент — один файл (.btn, .hero, .site-footer, …)
assets/               # шрифти (Unbounded, Mulish), фото, SVG-логотипи
DESIGN.md             # дизайн-система — джерело правди
```

## Шкала розмірів

Значення беруться лише з токенів (`styles/tokens.css`), у компонентних стилях —
жодних «магічних» чисел, тільки `var()`.

- **spacing** (4/8/16/32/64): `2 4 8 12 16 24 32 40 48 64 80 96 128` → `--space-2 … --space-128`
- **radius**: `2 4 8 12 16 24 9999` + `--radius-panel: 6px` (виняток, DESIGN.md §5.3)
- **border-width**: `1 2` → `--border-1 / --border-2`
- **icon**: `16 20 24 32 40` → `--icon-16 … --icon-40`
- **control-h** (фіксовані): `24 32 40 48 56` → `--control-h-24 … --control-h-56`

Не входять у шкалу (за правилами): `font-size / line-height / letter-spacing`,
відсотки, `vh/vw`, `fr`, `minmax`, `auto`, `aspect-ratio`, межі 1px, штрихи 1.5px,
тривалості анімацій.

Токени, що переносяться без зміни значень: кольори (примітиви бренд-буку + семантичні),
палітри світів, скрими, типографічна шкала (`--type-*`), motion.

## Імпорт у Figma (html.to.design)

1. `npm run dev` (або `npm run build && npm run preview`).
2. У плагіні html.to.design вкажіть URL сторінки (`/index.html` або `/styleguide.html`).
3. Імпортуйте окремо на ширині десктопу (**1280**) і мобільного (**390**) — це різні фрейми.

Що варто знати про експорт:

- **Логотипи, вордмарк і марка welldone** — реальні інлайн-`<svg>` (раніше були
  `mask-image`), тому потрапляють у Figma як вектор і фарбуються токеном.
- **Стани** `:hover/:focus/:active/:disabled` в експорт не потрапляють — на
  `styleguide.html` вони продубльовані статичними класами (`.btn--…`, `.is-hover`, …).
- **Абсолютні накладки** (фото + скрим + фігура в hero/footer) стають окремими фреймами —
  це очікувано.
- **Мобільне меню** (`:target`-оверлей) на десктопі приховане й у фрейм не потрапляє.
- Стан хедера при скролі (непрозорий spruce) — інтеракція, у статиці не відтворюється;
  експортується верхній стан (прозорий над hero).

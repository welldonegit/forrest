# Keyframes для Claude Design

Статичні кадри ключових станів анімацій `index.html`, які Claude Design не може
прочитати з коду (скраб-відео). Для таймінгів і механіки — `../claude-design-brief.md`.

## Хіро: скраб + FLIP у другий екран (ефект A-1 у брифі)
- `hero-p00-start.png` — старт: великий H1 над повноекранним кадром відео.
- `hero-p02.png` — H1 «відлітає» вгору (зменшується + зникає).
- `hero-p065-frame-full.png` — камера пройшла, кадр відео на весь екран, H1 зник.
- `hero-p085-flip.png` — FLIP: кадр стискається у правий слот 16:9, зліва проступає другий екран.
- `hero-p10-landed.png` — приземлення: другий екран («Дохід 365 днів»), картка-відео з чипом «60 сек».

## «Три світи» (ефект A-3) — потрібен ЗАПИС ЕКРАНА
Скраб-відео + покадровий SVG-спотлайт на будівлі headless зняти надійно не вдається.
Зніми екран на деплої: прокрути сцену так, щоб по черзі підсвітилися WIND → ROCK → SUN
(підсвічування = затемнення всього кадру з розмитою «діркою» у формі активної будівлі +
крапка-маркер із пульсами та лінія до підпису). Механіка — у брифі.

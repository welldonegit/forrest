# Бриф для перенесення головної у Claude Design

Claude Design **не вбудовує живу сторінку — він її перезбирає**: читає структуру, тексти й частину стилів за посиланням, а JS-/відео-анімації відтворює **за описом або записом екрана**. Тому нижче — точний опис кожної анімації (тригер, механіка, таймінги з коду), щоб відтворення було вірним.

Переносимо **два варіанти головної окремо**: `index.html` (головний концепт) і `soft.html` («м'який»).

---

## Що надіслати Claude Design (3 речі, як він просив)

1. **Посилання** на задеплоєну сторінку (Vercel): `/` — index, `/soft` — soft. Віддавати **повну** сторінку з усім JS, без reduced-motion.
2. **Короткий запис екрана** — **обов'язково** для скраб-ефектів (хіро та «Три світи»): вони працюють через `video.currentTime` по скролу, з коду їх відтворити точно не можна. Решту можна за цим описом. Запис з реального браузера на деплої — точніший за будь-який інший.
3. **Що переносити**: вся сторінка, по одному варіанту за раз. Спершу — головний (`index`).

**Найважче відтворити** (тільки через запис екрана): `index` — скраб хіро + «Три світи». Решта — чисті `transform/opacity/clip-path`, відтворюються за описом.

---

## ВАРІАНТ A — `index.html` (головний концепт)

### 1. Хіро: скраб по скролу + FLIP у другий екран ⚠️ потрібен запис
- **Тригер**: пінована секція ~400vh, прогрес `p` 0→1 по скролу. **Технологія**: нативний rAF + `video.currentTime` (без GSAP).
- **Механіка** (4 акти, що перекриваються):
  - `p 0→.40` — H1 «відлітає вгору»: `translateY` (ease-in `t²`) + `scale 1→0.6` + `opacity 1→0`.
  - `p .15→.65` — камера: `video.currentTime` 0→9s (скраб відео), решту тримається на крайніх кадрах.
  - `p .65→.80` — панель+статистика зникають: `opacity 1→0`.
  - `p .65→1` — **FLIP**: кадр відео масштабується з повноекранного cover у свій слот (права колонка 16:9), `translate+scale`, easeInOut. На ~93% з'являються чип «60 сек», play і CTA (`opacity 550ms`, `transform 650ms cubic-bezier(.22,1,.36,1)`, з `translateY(12px)`).
  - `p .75→1` — другий екран проявляється (`opacity 0→1`), відео темнішає на 50%.
- **Брейкпоінти**: пінований FLIP лише **≥1280**. `<1280` → статичний стек у два екрани (без скрабу).
- **Reduced-motion**: одразу статичний стек.

### 2. Модалка презентації хіро
- **Тригер**: клік по play. Відкриття `display:flex`, відео з 0 і play, lock скролу, focus-trap, закриття Esc / клік по тлу / хрестик.

### 3. «Три світи»: скраб + спотлайт на будівлі + маркери ⚠️ потрібен запис
- **Тригер**: пінована сцена, прогрес `g` 0→1. **Технологія**: нативний rAF + `video.currentTime` 0→18.48s + SVG-маска.
- **Механіка**:
  - Скраб відео по прогресу.
  - Перемикання активного світу на межах відео `6.5s` і `13.5s` → WIND / ROCK / SUN.
  - **Спотлайт** (не кільце): повнокадрове затемнення з розмитою (`blur 22`) чорною «діркою» у формі активної будівлі — будівля «підсвічується» контрастом. Полігон інтерполюється покадрово між ручними ключами, стежачи за дрейфом польоту.
  - **Крапка + 2 пульси** на центрі будівлі (`scale 1→4, opacity .45→0`, 2.4s infinite, другий із затримкою 1.2s) + **лінія-конектор** від підпису до крапки (`march` dashoffset, 1s linear infinite).
  - **Назва по літерах**: `opacity 0→1 + translateY(.55em)→0 + blur(9px)→0`, 0.6s ease-out, stagger 45ms; теглайн і опис із затримкою.
- **Брейкпоінти**: маркери/спотлайт/конектор лише **≥768**. **Reduced-motion**: статика, три тексти стеком, без скрабу.

### 4. Tri — поява заголовка
- **Тригер**: секція входить (30%). Маскові рядки `translateY(110%)→0`, `900ms cubic-bezier(.19,1,.22,1)`, stagger 40/150/260ms. Лід: `opacity+translateY(16px)` 700ms, затримка 400ms.

### 5. Tri — інтро FLIP-зум → згладжена колода карток
- **Тригер**: пінована сцена, прогрес згладжений щокадру (`current += (target-current)*0.07` — floema-лаг). **Технологія**: нативний rAF, лише transform.
- **Механіка**:
  - **Інтро**: повноекранне хіро «розкривається» зворотним FLIP зі слоту; бокові картки підтискаються під центр (`translateX ±92% scale`), потім хіро → повний екран.
  - **Колода**: кожен слайд піднімається `translateY 100%→0`, перекриваючи попередній; зони dwell/transition, easing `easeInOutQuint`; паралакс картинки всередині (`translateY ±64px`).
- **Брейкпоінти**: працює на всіх ширинах. Мобільне інтро: центр через `clip-path inset` «стає вертикальним» синхронно із зумом. **Reduced-motion**: статичний читабельний стек.

### 6. Tri — модалка світу (WIND/ROCK/SUN)
- **Тригер**: клік. Скрим `opacity 200ms`; діалог `opacity+translateY(16px) 400ms`; фото світів кросфейдить `300ms`; підписи міняються з фейдом; на мобільному «Детальніше» розкриває підпис. Focus-trap, Esc, клік по скриму.

### 7. Планування: портал-«занурення» *(спільний з soft)*
- **Тригер**: клік по картці планування, з точки кліку (`--px/--py`). Картинки `decode()` перед відкриттям.
- **Механіка** (origin = точка кліку):
  - Тло `opacity .25s`.
  - `swallow 1.13s` — план-картинка `scale 1→.62, opacity→0, blur 0→7px, brightness→.6` (віддаляється).
  - `open 1.33s cubic-bezier(.22,1,.36,1)` — кімната як діафрагма: `clip-path circle(0%→150%)`, `scale 1.14→1`.
  - `flash 1.23s` — білий спалах `opacity 0→.75→0`.
  - `appear .5s` — підпис і хрестик проявляються.
- **Підказка-тап** (у спокої): рука «натискає» + хвиля-ripple, 1.8s infinite.

### 8. Оверлей-меню (повноекранна навігація) *(спільне)*
- **Тригер**: бургер. Тло `opacity 250ms`; пункти піднімаються `translateY(100%)→0, 600ms cubic-bezier(.22,1,.36,1)`, stagger 70ms; картки `opacity+translateY(24px) 500ms`; футер `opacity 300ms`. Lock скролу, focus-trap, Esc.

### 9. Шапка по скролу
- `.is-scrolled` при `scrollY>8` (хайрлайн знизу); ховання при скролі вниз (після 120px) / поява вгору (`translateY(-100%)`, 250ms). Колір тексту не змінюється.

### 10. Поповер контактів
- **Тригер**: клік. Панель росте з правого-верхнього кута: закрито `translateY(-10px) scale(.96) opacity0` → відкрито, `170→340ms cubic-bezier(.22,1,.36,1)`. Рядки всередині stagger `opacity+translateY(8px)` 220ms.

### 11. Акордеон футера (лише мобільний)
- **Тригер**: тап по заголовку групи (≤767). Панель `grid-template-rows 0fr→1fr`, шеврон обертається, 200ms. Десктоп — статичні колонки.

## ВАРІАНТ B — `soft.html` («м'який» концепт)

**Стек**: GSAP + ScrollTrigger + **Lenis** (плавний скрол, `lerp 0.08`). Старт-стани на класі `html.s-anim`; при reduced-motion клас не додається, Lenis не стартує, контент завжди видимий.

### S1. Заголовки — маскова поява рядків
ScrollTrigger `top 88%`. `.line-in yPercent 112→0`, `1.2s expo.out`, stagger 0.08; рядки обрізані `overflow:hidden`.

### S2. Лід/CTA — fade-rise
`opacity0 translateY(24px)` → `opacity1 y0`, `1s power3.out`, `top 92%`.

### S3. Картки — поява зі зсувом
`.s-card opacity0 translateY(40px)` → in, `1.1s power3.out, stagger 0.12`, `top 86%`.

### S4. Картки-цифри — преміум-rise
`.s-num opacity0 translateY(60px)` → in, `1.2s expo.out, stagger 0.14`, `top 82%`.

### S5. Фото — розкриття по clip-path + зум усередині
`.s-reveal clip-path inset(42%→0% round 32px)` 1.6s expo.out; всередині `.s-reveal__img scale 1.15→1` одночасно.

### S6. Паралакс фото
`[data-parallax] yPercent -6→6`, `scrub:true`, `start top bottom / end bottom top` (зсув ≤8%).

### S7. Хіро — перемикач сезону (клік)
Клік по тумблеру: зимовий шар `clip-path circle(0%→150% at 93% 50%)`, `1200ms cubic-bezier(.76,0,.24,1)` — діафрагма з нижнього-правого кута. Іконка сніг↔сонце, підпис Зима↔Літо.

### S8. Плаваюча картка фінмоделі
При `scrollY > hero*0.72` → `.is-visible` (`opacity 550ms, transform 600ms, filter 550ms`). Закривається.

### S9. Розумна шапка
`.is-solid` при `scrollY > heroH-120` (скло→біле, backdrop-filter off); ховання вниз / поява вгору (`translateY(-150%)`, 250ms).

### S10. Soft-оверлей меню
Тло `opacity 400ms`; пункти й картки stagger `opacity 520ms / transform 620ms`.

### S11. Інлайн-відео сезону (клік)
Клік по play → `.is-playing` (зникає постер-оверлей, бейдж, play; `250ms`), unmute + `play()`, додаються `controls`.

### S12. Підказка-свайп у цифрах
`svg translateX ±7px`, 1.6s ease-in-out infinite.

### S13. Tri (soft-порт) — заголовок + FLIP-колода + модалка
Та сама структура, що index #4/#5/#6, з відмінностями:
- Колода м'якша: `EASE 0.055`, easing переходу `easeInOutSine` (замість quint).
- FLIP-хіро тримає **постійний радіус кута 40px** весь час (`borderRadius = 40/scale`).
- Вимір від пін-боксу (інсет 12px, 100vh−24px), не від вьюпорта.
- Модалка **без перемикання фото світів**; на мобільному — слайд-форма (`max-height 560ms`).

### S14. Планування: портал
Ідентичний index #7 (ті самі кадри `swallow/open/flash/appear`, ті самі таймінги).

### S15. Акордеон футера + сегментні контроли
Акордеон як index #11. Перемикач способу зв'язку й мови — зміна класів (без руху, крім hover).

---

## Спільне для обох
- **Hover кнопок/лінків**: підкреслення `scaleX(0→1)` зліва (`250ms`); колір/тло `150ms ease-out`.
- **Токени руху**: `hover 150ms`, `accordion 200ms`, `menu 250ms`, `entrance 400ms`; `ease-out cubic-bezier(.2,.6,.3,1)`; soft: `cubic-bezier(.22,1,.36,1)`. При reduced-motion усі → 0ms.
- **Свідомі винятки дизайну**: скраб-відео (хіро + світи), масивна типографіка Tri, нічний скрим 70% у модалці Tri.
